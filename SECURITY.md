# Security Policy

## Sobre este repositorio

Internet Honeypot Lab es un proyecto educativo y defensivo. La infraestructura utilizada durante el experimento fue eliminada al terminar la recogida de datos.

## Datos sensibles

Las evidencias públicas deben evitar publicar:

```text
IPs administrativas personales
IP completa del VPS
IPs completas de terceros
passwords administrativas
claves SSH privadas
tokens
cookies
API keys
credenciales de Hetzner
credenciales de T-Pot
```

## Malware y payloads

Este repositorio no debe contener malware capturado, payloads, binarios desconocidos o ejecutables provenientes de sesiones observadas.

Si se captura contenido potencialmente malicioso, conservar únicamente indicadores seguros como hashes, timestamps y metadatos sanitizados.

## Uso responsable

El laboratorio está diseñado para observación pasiva. No utilizar la información registrada para contraatacar, escanear IPs observadas, intentar acceder a sistemas externos o descargar payloads.
